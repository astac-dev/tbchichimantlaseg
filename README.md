# Telebachillerato Chichimantla Segundo

Este es el sitio web oficial del Telebachillerato Chichimantla Segundo, una institución educativa comprometida con la formación académica y el desarrollo integral de sus estudiantes. El sitio sirve como plataforma principal para la difusión de información institucional, actividades académicas, servicios en línea y contacto con la comunidad.

## Características Principales

- **Diseño Responsivo**: Interfaz optimizada para dispositivos móviles, tablets y computadoras de escritorio.
- **Información Institucional**: Sección "Nosotros" con misión y valores de la institución.
- **Actividades Paraescolares**: Presentación de diversas actividades como Danza, Ajedrez, Basquetbol, Programación y Robótica, entre otras.
- **Servicios en Línea**: Acceso directo al portal de alumnos para consulta de calificaciones y servicios académicos.
- **Gobernanza de IA**: Información detallada sobre el uso responsable y ético de la Inteligencia Artificial en el aula, incluyendo guías para estudiantes y padres.
- **Formularios de Contacto y Registro**: Herramientas para facilitar la comunicación con padres y la preinscripción de nuevos estudiantes.

## Estructura del Proyecto

- **`index.php`**: Página principal y punto de entrada al sitio.
- **`gobernanzaia.html`**: Guía completa sobre la gobernanza de Inteligencia Artificial.
- **`css/`**: Hojas de estilo para el diseño y la maquetación.
- **`img/`**: Recursos gráficos, incluyendo el logo institucional, imágenes de fondo y fotografías de actividades.

## Cómo Empezar

1. **Requisitos**: Servidor web con soporte para PHP y MySQL.
2. **Instalación**:
   - Clonar o descargar el repositorio.
   - Subir los archivos al directorio raíz de su servidor web (ej. `htdocs`, `www`).
   - Asegurarse de que los enlaces internos y externos sean correctos.
